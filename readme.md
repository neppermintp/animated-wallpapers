# Getting an animated wallpaper

https://github.com/mmhobi7/xwinwrap

## Wallpaper script

Single-monitor solution nicked from [github](https://github.com/StefanAngelovski/Linux-Mint-Animated-Wallpapers/tree/master).

## Video trim
You need a video to loop. If you have one that loops nice already, great. If you need it to loop, then you'll want to edit the video to make it loop nicely. This means taking the original video, copying it, removing the first and last frames, and then appending the reversed video to the end of the original. This keeps the "periodic boundary conditions" from having a repeated frame.
